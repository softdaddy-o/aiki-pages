Ultra(울트라)

다른 이름: ultraUltraAI UltraGoogle AI Ultra구글 AI 울트라

Ultra는 Google AI Ultra를 줄여 부르는 말로, Google이 Gemini 앱과 여러 AI 제품의 상위 사용량과 일부 선공개 기능을 묶어 파는 개인용 구독 등급이야. 모델명이나 API 권한으로 읽으면 금방 헷갈려.

한 줄 정의

Ultra(울트라)는 보통 Google AI Ultra를 줄여 부르는 말이야. Gemini 모델 이름도 아니고, 개발자가 서버에서 부르는 Gemini API 권한도 아니야. 개인 Google 계정에 붙는 상위 구독 등급으로 봐야 해.

2026년 5월 7일 확인 기준으로 Google의 Gemini 구독 페이지는 Google AI Ultra를 Google AI Pro보다 높은 유료 등급으로 놓고, 월 249.99달러, 30TB 저장공간, 150개가 넘는 국가 제공을 안내해. 그래서 이 이름이 보이면 “어떤 모델이냐”보다 “어떤 계정이 어떤 사용량과 선공개 기능을 받느냐”부터 봐야 해.

이름층위먼저 볼 것
Google AI Ultra개인용 구독 등급월 249.99달러를 낼 만큼 사용량, 영상 생성, 연구, 코딩 보조, Google 앱 통합을 자주 쓰는지 봐.
Pro라고 표시된 모델Gemini 앱 안의 모델 선택구독 이름이 아니라, 프롬프트 바에서 고르는 모델 계열 표시야. Pro 표시 기능이 모두 Ultra 전용은 아니야.
Gemini API 호출 경로개발자 호출 경로앱이나 서버가 모델을 호출하면 토큰 과금, 키 관리, 장애 대응을 따로 계산해야 해.

이 셋을 섞으면 비용표가 바로 꼬여. “Ultra를 쓴다”는 말은 계정의 구독 등급을 말하는지, 앱에서 고른 모델을 말하는지, 서버 호출을 말하는지 다시 물어야 해.

실제로 무엇을 하나

Ultra는 하나의 기능보다 묶음에 가까워. 2026년 5월 7일 확인 기준 조건표를 보면 혜택은 크게 세 덩어리로 나뉘어.

  • 모델·생성: Gemini 앱의 상위 사용량 한도, Veo 3.1 영상 생성, Deep Think, Gemini Agent, Project Genie.
  • 업무·개발: Google Search의 Deep Search와 여러 단계를 이어 가는 자동 기능, Jules, Gemini Code Assist, Gemini 명령줄 도구(CLI), Google Antigravity, NotebookLM.
  • Google 제품 묶음: Gmail·Docs·Vids 안의 Gemini, Google Home Premium Advanced, YouTube 개인 플랜, Photos·Drive·Gmail 전체 30TB 저장공간.

출시 당시 방향도 비슷했어. 2025년 5월 발표는 Ultra를 상위 사용량과 고급 모델·기능 접근권을 받는 구독으로 소개했고, Gemini 앱, Flow, Whisk, NotebookLM, Gemini in Chrome, Project Mariner, 동영상 구독 혜택, 30TB 저장공간을 예로 들었어. I/O 2025 Gemini 앱 발표도 사용량 한도와 선공개 기능을 넓히는 플랜으로 설명했지.

다만 모든 새 기능이 Ultra 전용이라는 뜻은 아니야. 2026년 3D 모델·인터랙티브 차트 발표는 Gemini 앱 사용자가 Pro라고 표시된 모델 선택지를 골라 시각화를 만들 수 있고, 전 세계 모든 Gemini 앱 사용자에게 롤아웃된다고 적었어. 반대로 2026년 4월 이미지 생성 개인화 기능은 미국의 Google AI Plus, Pro, Ultra 구독자에게 며칠에 걸쳐 열린다고 설명됐어. 같은 Gemini 안에서도 기능마다 무료, Plus, Pro, Ultra, 지역, 계정 조건이 갈리는 거야.

왜 중요한가

Ultra가 중요한 이유는 AI 기능 구매가 모델 성능표만으로 끝나지 않기 때문이야. 영상 생성, 긴 리서치, 코드 보조, Google 앱 통합, 저장공간까지 같이 쓰는 사람에게는 한 달 구독료와 사용량 한도가 먼저 보인다. 반대로 특정 앱에서 모델을 몇 번 호출하는 제품을 만들고 있다면 Ultra가 아니라 API 가격표와 권한 검토가 먼저야.

예를 들어 개인 창작자가 Flow에서 영상 시안을 만들고, Veo로 짧은 클립을 뽑고, NotebookLM으로 자료를 정리하고, Gemini Code Assist로 코드 작업을 자주 한다면 Ultra는 한 계정 안에서 한도를 넓히는 선택지가 될 수 있어. 하지만 회사 백엔드가 고객 요청마다 Gemini를 호출하는 구조라면 개인 구독권으로 처리할 일이 아니야. 그건 API 키, 서비스 계정, 로깅, 예산 알림을 따로 설계해야 하는 문제야.

또 “울트라”라는 단어는 제품마다 다르게 붙어. ChatGPT Pro나 Claude Pro처럼 상위 개인 구독을 뜻할 때도 있고, 과거 모델명이나 마케팅 표현에 붙을 때도 있어. 문서나 비용표에는 Google AI Ultra, Gemini 앱의 Pro 표시 모델, Gemini API의 호출 모델 식별자처럼 실제 이름을 따로 적는 편이 나중에 덜 헷갈려.

주의해서 볼 점

첫째, 상위 한도라는 표현을 무제한으로 읽으면 안 돼. 조건표도 기능마다 제한을 나눠 적어. Gemini Agent는 미국 한정, 영어 한정이라고 표시돼 있고, 동영상 구독 개인 플랜은 40개가 넘는 국가에서 제공된다고 따로 설명돼. Ultra가 넓은 권한을 주는 건 맞지만, 지역·언어·계정·제품별 제한은 계속 남아.

둘째, 개인화 기능은 구독료보다 데이터 범위가 먼저야. Nano Banana와 Google Photos 맥락을 함께 쓰는 경우, 어떤 사진이 자동 선택됐는지 Sources 버튼으로 확인할 수 있다고 Google은 설명해. 가족 사진이나 고객 이미지처럼 민감한 자료가 들어간다면 “Ultra니까 된다”가 아니라, 어떤 계정 데이터가 답변과 이미지 생성에 들어가는지 먼저 봐야 해.

셋째, 비용 비교는 작업 단위로 해야 해. Ultra는 월 249.99달러 구독이고, 조건표는 업로드 문서 최대 1,500페이지, 코드 저장소 최대 30,000줄 같은 사용 장면을 보여 줘. 하지만 개발자 API는 토큰, 캐시, 요청 수, 장애 대응 비용으로 계산돼. 개인이 화면에서 쓰는 한도와 제품이 자동으로 호출하는 비용은 같은 표에 넣으면 안 돼.

같이 보면 좋은 항목

  • Gemini: Ultra가 접근권을 넓혀 주는 Google의 큰 모델·서비스 브랜드야. 모델 계열과 구독 등급을 분리해서 볼 때 필요해.
  • Personal Intelligence: Ultra와 함께 언급되는 개인화 기능이야. 구독 조건보다 계정 데이터 연결 범위를 먼저 보게 해줘.
  • Nano Banana: Gemini 앱의 이미지 생성·편집 모델 축이야. Plus, Pro, Ultra 같은 구독 조건과 모델 이름이 어떻게 갈리는지 보기 좋아.
  • Veo: Ultra에서 높은 접근권을 주는 영상 생성 모델 축이야. 이미지 생성과 영상 생성 비용을 나눠 볼 때 같이 봐.
  • ChatGPT Pro: 상위 개인 구독이라는 점에서 비교 대상이야. 다만 구독권과 API 권한이 다르다는 경계가 더 중요해.
  • Claude Pro: 개인용 구독과 Claude Code 사용량을 묶어 보는 사례야. Ultra처럼 “모델명인가, 구독명인가”를 가르는 데 도움돼.

Ultra를 모델명, API 크레딧, 무제한권, 모든 Gemini 기능의 필수 조건으로 읽는 오해를 줄이는 쪽으로 점검했어.
  • Ultra는 Gemini 모델군이나 Gemini API 모델 ID가 아니라 개인 계정의 구독 등급이야. 서버 제품에서 Gemini를 호출하려면 API 과금과 권한을 따로 봐야 해.

  • 3D 모델·차트 기능처럼 모든 Gemini 사용자에게 열리는 기능도 있어서, Ultra는 기능 자체의 이름보다 사용량·선공개·묶음 혜택을 보는 항목으로 두는 게 안전해.

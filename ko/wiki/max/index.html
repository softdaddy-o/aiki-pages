Max(맥스)

다른 이름: maxMax

Max는 보통 Anthropic의 Claude 개인용 상위 유료 구독 등급을 뜻해. claude.ai에서 더 넓은 사용량과 기능 우선권을 주는 요금제라서, 기사에서 보이면 새 모델보다 구독 맥락부터 보는 편이 맞아.

한 줄 정의

기사에서 Max 사용자라는 말을 봤다면 먼저 장면을 갈라 보면 돼. 대개는 claude.ai에서 Claude를 더 오래, 더 자주 쓰게 해 주는 개인용 상위 구독을 가리키고, 새 모델 출시나 Anthropic API 예산 얘기는 보통 다른 문맥이야.

즉 Max는 Anthropic이 파는 Claude 개인용 상위 유료 구독 등급이야. Claude Opus 4.6이나 Claude Sonnet 4.5처럼 모델 자체를 부르는 말이라기보다, 그 모델들을 어떤 제품 안에서 어느 정도까지 쓰게 해 주는 소비자용 플랜에 가깝다. Plus와 같은 구독 층위에 놓이고, Anthropic API처럼 토큰 단위로 청구되는 개발자 과금과는 계산 방식이 다르다.

실제로 무엇을 하나

Max는 같은 Claude 경험 안에서 더 오래, 더 자주 쓰게 해 주는 상위 플랜이야. 2026-05-03 기준 공식 도움말은 Max를 두 단계로 나눠 적고 있어.

  • Max 5x: 월 100달러(공식 가격), Pro보다 세션당 5배 사용량, 짧은 대화 기준 5시간마다 최소 225메시지(공식 사용량) 수준
  • Max 20x: 월 200달러(공식 가격), Pro보다 세션당 20배 사용량, 짧은 대화 기준 5시간마다 최소 900메시지(공식 사용량) 수준
  • 컨텍스트 창: Max도 다른 Claude 플랜과 같이 200K(공식 플랜 안내)

여기서 실무적으로 자주 헷갈리는 지점은 청구 바구니야. Max는 Claude Code 같은 Claude 제품 경험 안에서 사용량을 넓혀 주는 개인용 구독이고, 공식 문서도 Max 사용량이 일반 Claude와 Claude Code에 함께 적용된다고 적어. 반대로 Anthropic API는 토큰 단위 과금이 따로 돈다. 그래서 Plus보다 넉넉한 개인용 구독으로 이해하면 맞고, API 크레딧 묶음처럼 읽으면 문맥이 어긋나.

왜 중요한가

이 단어를 알아두면 기사 해석이 훨씬 덜 꼬여. 뉴스에서 Max 사용자가 늘었다는 문장을 보면, 먼저 떠올려야 할 건 모델 성능 개선보다 개인용 고사용량 구독층 확대야. Anthropic이 claude.ai 사용자에게 어떤 요금제를 얼마나 밀고 있는지 읽는 쪽이 보통 더 정확하거든.

2026년 4월 4일 맥락에서는 더 중요했어. VentureBeat와 TNW 보도를 보면 Anthropic은 그날부터 Pro와 Max 구독을 OpenClaw 같은 외부 하네스에 붙여 쓰는 길을 막고, 계속 쓰려면 extra usage나 API 과금으로 넘어가게 했어. 그러니까 Max는 “Claude를 많이 쓰는 개인용 플랜”이지, 외부 agent 런타임까지 다 덮는 정액 개발자 패스는 아니라는 경계가 그 시점에 더 선명해졌어.

주의해서 볼 점

첫째, Max를 무제한 패스로 읽으면 과해져. 공식 usage 문서는 5시간 세션 기준을 쓰고, 추가 주간·월간 제한이나 기능별 제한이 붙을 수 있다고 같이 적어.

둘째, Max와 API를 같은 지갑으로 보면 헷갈려. Max는 소비자용 구독이고, Anthropic API는 토큰 단위 과금이야. 같은 Claude 이름을 쓰더라도 청구 방식과 운영 경계가 다르다.

셋째, 2026-04-04 이후 기사에서 Max가 보이면 외부 에이전트 연결 가능 여부를 같이 봐야 해. Claude 안에서 많이 쓰는 플랜인지, 아니면 바깥 하네스까지 포함한 자동화 경로인지가 완전히 다른 얘기라서 그래.

  • How much does the Max plan cost 문서는 Max를 월 $100, 월 $200의 두 단계로 나누고 월간 구독만 가능하다고 적어, 본문에 넣은 가격과 결제 구조를 다시 고정해 줘.
  • VentureBeat와 TNW 기사도 2026-04-04 차단 대상을 Claude Pro·Max subscription으로 적어서, 외부 하네스 이슈가 모델이 아니라 구독 플랜 경계 문제였다는 점을 확인해 줘.

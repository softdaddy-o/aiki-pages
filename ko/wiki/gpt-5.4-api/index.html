GPT-5.4 API (지피티 5.4 API)

다른 이름: gpt 5.4 apiGPT-5.4 API

GPT-5.4 API는 OpenAI API에서 `gpt-5.4` 모델 ID로 GPT-5.4를 호출하는 개발자용 경로야. 긴 문맥, 도구 사용, 코딩 에이전트, 컴퓨터 사용 작업을 API 안에서 다룰 때 기준점이 돼.

모델 프로필

모델을 고를 때 먼저 확인할 것만 모았어. 어려운 말은 링크를 눌러 뜻부터 잡으면 돼.

길이와 메모리

API 모델 카드 기준 문맥 창은 1,050,000토큰이고 최대 출력은 128,000토큰이야. OpenAI가 호스팅하는 비공개 모델이라 로컬 GPU VRAM 표로 고르는 모델은 아니야.

한 번에 읽을 수 있는 글·코드 길이와 실제 실행에 필요한 메모리를 같이 보는 칸이야.

모델 방식

OpenAI가 API에서 `gpt-5.4`라는 모델 ID로 제공하는 GPT-5.4 호출 경로야. ChatGPT의 Thinking 표시나 Codex 제품명보다, 개발자가 엔드포인트에 붙이는 모델 선택값에 가까워.

모델이 어떤 방식으로 만들어졌는지 보는 칸이야. MoE, Transformer, 비전 인코더처럼 낯선 말은 링크로 확인하면 돼.

전체 크기와 켜지는 크기

총 파라미터나 활성 파라미터 수는 공개되지 않았어. 대신 `reasoning.effort`는 `none`, `low`, `medium`, `high`, `xhigh`를 지원하고 스냅샷은 `gpt-5.4-2026-03-05`로 고정할 수 있어.

모델 전체가 얼마나 큰지, 답을 만들 때 그중 얼마가 실제로 쓰이는지 나눠 보는 칸이야.

입력과 출력

텍스트와 이미지를 입력으로 받고 텍스트를 출력해. 모델 카드 기준 오디오와 비디오는 지원하지 않아.

텍스트만 쓰는지, 이미지·음성·영상도 받는지, 결과는 어떤 형태로 나오는지 확인해.

사용 방법

API 모델 ID는 `gpt-5.4`야. Chat Completions, Responses, Realtime, Assistants, Batch에서 부를 수 있고, Responses API에서는 도구 지원 범위가 가장 넓게 드러나.

앱에서 고르는지, API로 호출하는지, 모델 파일을 내려받아 직접 운영하는지 보는 칸이야.

가격

표준 짧은 문맥 가격은 100만 토큰당 입력 $2.50, 캐시 입력 $0.25, 출력 $15.00이야. 긴 문맥 가격은 입력 $5.00, 캐시 입력 $0.50, 출력 $22.50이고 272K 입력 초과 세션에는 별도 배율이 붙어.

API 요금인지, 직접 운영할 때 드는 GPU·저장공간·트래픽 비용인지 나눠 읽으면 돼.

모델 파일 공개

아니야. 공식 문서는 API와 제품 경로를 안내할 뿐, 가중치 다운로드나 로컬 실행 패키지를 제공하지 않아.

모델 파일을 내려받아 직접 실행할 수 있는지, 서비스나 API로만 써야 하는지 확인해.

한 줄 정의

GPT-5.4 API (지피티 5.4 API)는 모델 자체의 새 이름이라기보다, OpenAI API에서 gpt-5.4 모델 ID로 GPT-5.4를 부르는 개발자용 호출 경로야. ChatGPT에서 보이는 GPT-5.4 Thinking 같은 제품 표시가 아니라, 코드가 Responses API나 Chat Completions 같은 엔드포인트에 보내는 모델 선택값에 더 가까워.

예를 들어 사내 문서 200개를 읽고, 브라우저 화면을 확인하고, 코드 저장소를 고친 뒤, 마지막에 변경 이유까지 남기는 에이전틱 코딩 흐름이라면 gpt-5.4를 API에서 직접 부를 수 있어. 반대로 사람이 ChatGPT 화면에서 긴 답변의 계획을 보고 중간에 방향을 바꾸려는 일이라면 gpt-5.4 API가 아니라 GPT-5.4 Thinking 쪽 이름을 먼저 봐야 해.

이 모델로 무엇을 할 수 있나

API 모델 카드 기준으로 gpt-5.4는 텍스트와 이미지 입력을 받고 텍스트를 출력해. 문맥 창은 1,050,000토큰, 최대 출력은 128,000토큰이라서 짧은 챗봇 답변보다 긴 문서 묶음, 코드베이스, 도구 실행 로그를 한 세션 안에서 다루는 작업에 맞아. reasoning.effort는 none, low, medium, high, xhigh를 지원해서 속도와 추론 깊이를 요청별로 나눌 수 있어.

Responses API에서 보이는 도구 범위도 중요해. 모델 카드는 아래 묶음을 지원한다고 적어.

  • 검색과 자료 회수: 웹 검색, 파일 검색, MCP, tool search가 여기 들어가. 판단 기준은 “모델이 답만 쓰면 되는가, 아니면 필요한 도구 정의를 찾아 붙여야 하는가”야.
  • 실행과 수정: 코드 인터프리터, 호스티드 셸, apply patch, skills는 파일을 만들고 고치거나 실행 결과를 확인하는 쪽에 가까워. 코드베이스 작업이나 자동 검증 루프가 있으면 이 묶음을 먼저 봐야 해.
  • 화면과 산출물: 이미지 생성과 컴퓨터 사용은 화면을 보거나 새 시각 산출물을 만드는 작업에 붙어. 브라우저 조작, 스크린샷 기반 클릭, 문서 안 이미지 생성처럼 텍스트 바깥의 상태가 있으면 이 묶음이 중요해.

다만 모든 기능을 한 번에 켠다는 뜻은 아니야. 짧은 텍스트 응답이나 기존 chat.completions 호환이 목적이면 Chat Completions가 더 단순해. 도구 검색, 컴퓨터 사용, MCP, 호스티드 셸처럼 여러 상태를 이어 가야 하면 Responses API 쪽이 맞아. 같은 gpt-5.4라도 엔드포인트, 도구, reasoning 설정, 스냅샷 고정 여부가 달라지면 비용과 재현성이 달라져.

왜 중요한가

GPT-5.4 API가 중요한 이유는 모델 발표를 실제 운영값으로 바꿔 주는 지점이기 때문이야. 출시 글은 GPT-5.4를 ChatGPT, API, Codex에 동시에 열었다고 설명하지만, 개발자가 비용을 계산하고 장애를 줄이려면 결국 API 모델 카드의 gpt-5.4, 스냅샷 gpt-5.4-2026-03-05, 엔드포인트, 도구 지원을 따로 봐야 해.

가격도 여기서 갈려. 표준 짧은 문맥 기준 gpt-5.4는 100만 토큰당 입력 $2.50, 캐시 입력 $0.25, 출력 $15.00이야. 긴 문맥 Standard 가격표에서는 입력 $5.00, 캐시 입력 $0.50, 출력 $22.50으로 올라가고, 272K 입력을 넘는 1.05M 문맥 세션은 세션 전체에 입력 2배와 출력 1.5배 규칙이 붙어. 지역 처리 엔드포인트에는 10% 할증도 있어.

이 숫자는 모델 선택을 꽤 현실적으로 바꿔. 짧은 분류, 반복 요약, 테스트용 하위 에이전트라면 GPT-5.4 Mini처럼 더 싼 경로를 먼저 볼 수 있어. 반대로 긴 코드 수정, 화면 조작, 도구 검색, 문서 생성이 섞이고 실패 비용이 큰 작업이면 기본 gpt-5.4가 기준선이 돼. 최대 성능이 필요하면 GPT-5.4 Pro까지 비교하지만, 가격 차이가 크기 때문에 기본값으로 올리기 전에 실제 샘플 작업으로 재봐야 해.

같이 보면 좋은 모델

  • GPT-5.4: API, ChatGPT, Codex까지 포함한 GPT-5.4 전체 포지션을 볼 때 기준이 되는 상위 문서야.
  • GPT-5.4 Thinking: ChatGPT에서 보이는 긴 추론 제품 경로야. API 구현에서는 별도 gpt-5.4-thinking 모델 ID가 아니라 gpt-5.4와 reasoning 설정을 봐야 해.
  • GPT-5.4 Mini: 짧은 분류, 반복 요약, 테스트용 하위 에이전트처럼 비용과 속도가 먼저인 작업에서 비교할 후보야.
  • GPT-5.4 Pro: 더 비싸고 더 무거운 Pro 경로야. 복잡한 조사·분석·코딩 작업에서 기본 gpt-5.4로 부족한지 확인한 뒤 비교하는 편이 좋아.

OpenAI, 생명과학 모델 GPT-Rosalind를 바이오디펜스 파트너에 개방

OpenAI가 생명과학 모델 GPT-Rosalind를 팬데믹 대비에 쓰도록 검증된 개발자·정부 기관에 지원하는 Rosalind Biodefense 프로그램을 발표했어. 로런스 리버모어 국립연구소, 존스홉킨스 APL, CEPI 등이 초기 파트너로 참여해.

OpenAI가 생명과학 모델 GPT-Rosalind를 팬데믹 대비에 쓰도록 푸는 Rosalind Biodefense 프로그램을 2026년 5월 29일 발표했어. 핵심은 이 모델을 아무나가 아니라 “검증된 개발자(trusted developers)“한테만 지원한다는 거야. 역학 모델링, 조기 탐지, 스크리닝, 비약물적 개입(NPI) 같은 공중보건 도구를 만드는 팀한테 모델 접근과 출시 지원을 같이 주는 구조야.

이렇게 가는 이유가 있어. 강력한 생명과학 AI는 질병을 막는 방어에도 쓰지만, 위험한 쪽으로도 쓸 수 있는 이중용도 기술이거든. OpenAI는 이런 기술이 “방어하는 쪽”한테 확실히 유리하게 작동해야 한다고 봤고, 그러려면 아무한테나 푸는 게 아니라 심사를 거친 파트너한테만 여는 trusted access 방식이 필요하다고 판단했어. 백악관과 여러 연방 기관에 접근 방식을 미리 브리핑하기도 했어.

협력 기관 명단이 꽤 무거워. 미국 CAISI, 영국 AISI, 로스앨러모스 국립연구소, Frontier Model Forum이 외부 협력자로 들어가 있고, 초기 참여 기관으로는 로런스 리버모어 국립연구소, 존스홉킨스 응용물리연구소(APL), Fourth Eon Biosecurity, 그리고 백신 신속 개발을 맡는 CEPI 네 곳이 이름을 올렸어.

실무 관점에서 이건 “강력한 AI를 누구한테 어떤 조건으로 여느냐”는 문제의 한 답안이야. 다만 OpenAI 자체 발표라 모델 성능과 안전장치 효과는 독립 검증이 따로 필요하고, ‘검증된 개발자’라는 심사 기준이 실제로 얼마나 촘촘한지도 더 공개돼야 판단할 수 있어. AI가 백신 개발을 실제로 얼마나 앞당기는지 정량 성과는 아직 안 나왔거든.

2026-07-26 🔥80점 · 출처 5 원문 Anthropic - Claude Opus 5

Claude Opus 5, Fable 5의 절반 가격으로 나왔지만 성능 판단은 아직 따로 봐야 해

Claude Opus 5는 입력 100만 토큰 $5, 출력 100만 토큰 $25로 나왔어. 가격은 6월 공개된 Fable 5의 정확히 절반이지만, Anthropic이 제시한 0.5% 벤치마크 차이를 곧바로 실사용 등가로 읽으면 안 돼. Claude.ai·API·Claude Code·Claude Cowork에 같은 날 열렸고, 다음 단계는 자기 작업 기준으로 다시 재보는 거야.

가격은 절반으로 내려왔지만 성능 판단은 아직 보류야

Anthropic(앤트로픽)이 7월 24일 Claude Opus(클로드 오퍼스) 5를 공개하면서 붙인 가격은 입력 100만 토큰 $5, 출력 100만 토큰 $25야. 공식 발표 기준으로 6월에 나온 Claude Fable 5(클로드 페이블 5)의 입력 $10, 출력 $50과 비교하면 입출력 단가가 정확히 절반으로 내려왔어.

이 숫자는 가격 사실로는 분명하지만, 곧바로 “같은 일을 절반 값에 한다”는 뜻은 아니야. Anthropic이 함께 내놓은 근거는 대부분 자사 benchmark (벤치마크) 결과라서, 실제 전환 판단은 별도로 다시 재봐야 해.

지금 바로 바뀌는 점

같은 날 열린 경로는 네 군데야.

  • claude.ai(클로드 웹 앱): 웹과 앱에서 바로 선택할 수 있어.
  • API: 모델 ID는 claude-opus-5야.
  • Claude Code(클로드 코드): 터미널에서 쓰는 코딩 AI Agent (AI 에이전트)에 붙었어.
  • Claude Cowork(클로드 코워크): 업무용 Workspace(워크스페이스)에서도 같은 날 열렸어.

Fast mode도 같이 왔는데, 기본 가격의 2배를 내면 약 2.5배 빠르게 돌아가는 옵션이야. 지금 당장 바뀌는 운영 판단은 단순해. 급하지 않은 배치 작업은 기본 가격으로 보고, 지연 시간이 중요한 구간만 Fast mode를 붙여 보는 쪽이 먼저야.

벤치마크 숫자는 전부 자체 발표야

Anthropic이 내놓은 항목은 코딩과 컴퓨터 조작 쪽에 몰려 있어. 공식 발표에서는 CursorBench 3.2에서 Claude Fable 5(클로드 페이블 5) 최고 점수와 0.5% 안쪽 차이라고 밝혔고, ARC-AGI 3에서는 차순위 모델 대비 3배 점수라고 적었어. 다만 ARC-AGI 3의 비교 대상 모델명은 공식 발표에 없고, OSWorld 2.0도 비용을 함께 놓고 보면 다른 모델보다 앞선다는 표현만 있어.

다만 이 숫자는 전부 Anthropic이 자기 발표에 실은 값이고, 독립 기관 재현 결과는 아직 안 나왔어. 모델 교체를 검토한다면 벤치마크 요약보다 자기 코드베이스와 실제 프롬프트, Context(컨텍스트) 조건으로 다시 돌려보는 편이 빨라.

도입 판단은 여기서 갈려

공식 발표가 불리한 항목도 같이 적어놨어. 사이버보안 취약점 악용 능력에서는 Mythos (마이토스) 5보다 뒤에 있다고 밝혔고, 바이너리 기반 취약점 스캔·모의침투·익스플로잇 생성은 안전장치로 막아뒀다고 했어. 보안 도구를 만들려던 팀이라면 가격이 더 싸도 이 제한 때문에 바로 옮길 이유가 약해.

컨텍스트 길이와 최대 출력 토큰은 이번 공식 발표에 없어. 긴 문서를 통째로 넣는 작업이 주 용도라면 가격만 보고 옮기기 전에 API 문서 쪽 수치를 따로 확인하는 게 나아.

다음 단계는 자기 작업으로 다시 재는 거야

이번 발표로 바로 바뀐 건 가격과 접근 경로야. 다음 단계는 Fable 5에 태우던 대표 작업을 추려서 기본 가격, Fast mode, 보안 제한, 긴 문서 처리 조건까지 같은 기준으로 다시 재보고 옮길지 결정하는 거야.

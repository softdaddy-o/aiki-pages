2026-04-29 🔥81점 · 출처 4 원문 XDA — Anthropic charging Claude Code Pro users extra for Opus

Anthropic, Pro 플랜 Opus 제한 문서는 실수였다고 정정했어

Anthropic의 Claude Code 지원 페이지에 'Pro 플랜은 추가 사용량을 구매해야 Opus 사용 가능'이라는 경고가 떴고 Reddit이 268+ 댓글로 끓었어. Anthropic은 4월 28일 21:42 EST에 Reddit으로 공식 정정했어 — 문서 업데이트 누락이지 정책 변경이 아니라고 했고, 변경 시 사전 공지를 약속했어. 다만 같은 시기 Pro 가격표에서 Claude Code 체크가 빠진 'small test'(2% 신규 가입자)는 별개로 진행 중이야.

무슨 일이 일어났나

Anthropic의 Claude Code 지원 페이지에 4월 27일경부터 이런 경고가 떴어 — “Pro 플랜으로 Claude Code를 쓸 때는 추가 사용량을 활성화하고 구매해야 Opus 모델을 쓸 수 있다.” Reddit 스레드는 274+ 추천에 102 댓글까지 올라가면서 끓었어.

Anthropic은 4월 28일 21:42 EST에 Reddit으로 공식 정정했어. 문서 업데이트 누락이지 정책 변경이 아니라고 했고, “변경이 있으면 기존 가입자에게 충분히 사전 공지하겠다”고 했어. Wayback Machine 기록으로 보면 같은 경고 문구가 Opus 4.5·4.6·4.7 버전 동안 계속 남아 있었던 게 확인됐어 — 모델 리스트는 갱신했는데 접근 제한 경고만 안 지운 거야.

왜 이게 일어났나

별개의 이슈도 같이 진행 중이야. Anthropic 가격표에서 Pro 티어($20/월) 옆에 Claude Code 체크가 사라지고 X로 바뀐 시점이 4월 21일경이었어. Simon Willison의 정리에 따르면 Anthropic 성장 책임자 Amol Avasare가 X에서 답했어 — “신규 prosumer 가입자 약 2%에 small test를 돌리는 중이고, 기존 Pro·Max 가입자는 영향 없다.”

배경은 단순해. Pro $20에 Claude Opus 4.7을 종일 돌리면 추론 비용이 마진을 10배 이상 깨. Opus 4.7 API 가격이 $5/$25 per 1M 토큰인데, 헤비 사용자는 일일 1M 토큰을 가볍게 넘겨. 이번 문서 정정은 별개 이슈를 가리지 않아.

어떤 의미인가

지금 Pro $20으로 Claude Code Opus를 쓰고 있다면 단기는 안전해 — 정정 발언이 있고 기존 가입자 보호 약속이 있어. 다만 다음 두 가지를 같이 봐야 해:

  • “plenty of notice” 약속: 며칠인지, 몇 주인지 명시 안 됨
  • 신규 가입자 2% 테스트: Pro 가격표에서 Claude Code 자체가 빠지는 시그널

본인이 이미 Pro 사용자고 일일 작업이 4-5시간 미만이면 한 분기 관망이 합리적이야. 일일 8시간씩 돌리면서 /usage로 토큰 소모를 보면 이미 예상 마진을 넘는 게 보일 거야 — 그러면 Max 5x($100/월)로 올리는 게 정책 변경 시 충격이 작아.

다음 수순

/usage 명령으로 본인 일일 Opus 토큰 사용량을 일주일 측정해. 50만 토큰 미만이면 Pro 유지, 100만+ 면 Max 검토. Anthropic 가격 페이지와 Claude Code 지원 문서를 즐겨찾기에 두고, 다음 분기에 한 번 더 변경 여부를 확인해. GPT-5.5 on Bedrock 같은 대안이 같은 가격대에 들어왔으니 라우팅 옵션을 한 번 짜둘 가치는 있어.

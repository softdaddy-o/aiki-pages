MiniMax, M2.7 모델 공개 후 라이선스를 비상업으로 바꿔 논란

MiniMax가 에이전트 특화 모델 M2.7의 가중치를 Hugging Face에 공개한 뒤, 라이선스를 비상업용으로 변경했다. SWE-Pro 56.22%, Terminal Bench 2 57.0%를 기록한 모델이지만, 상업적 사용에는 사전 서면 승인이 필요해져 스타트업과 추론 제공업체에 실질적 장벽이 생겼다.

무슨 일이 있었나

MiniMax가 자사 최강 에이전트 모델 MiniMax M2.7의 가중치를 Hugging Face에 올린 뒤, 라이선스를 슬쩍 비상업용으로 바꿨어. 3월 18일 발표 당시 “오픈소스”라고 했는데, 정작 상업적 사용에는 사전 서면 승인이 필요하고 “Built with MiniMax M2.7” 표기까지 의무화했거든. 오픈소스가 아니라 source-available 라이선스인 셈이야.

왜 중요할까

성능 자체는 인상 깊어. SWE-Pro 56.22%, Terminal Bench 2 57.0%, SWE Multilingual 76.5%를 찍었고, MoE 아키텍처 덕분에 추론 비용도 낮은 편이야. 자체 최적화 라운드 100회 이상을 돌려 내부 평가 세트에서 30% 성능 향상을 달성한 “자가 진화(self-evolving)” 메커니즘도 독특하고.

앞으로 볼 점

문제는 커뮤니티 반응이야. Hugging Face 토론방에서는 “오픈소스라고 부르지 마라”는 비판이 바로 터졌어. 파인튜닝한 파생 모델이나 생성된 결과물에도 상업적 제한이 걸리는지가 불명확해서, 스타트업이나 추론 API 제공업체 입장에서는 법적 리스크가 커. M2.7을 프로덕션에 넣으려면 라이선스 전문을 먼저 읽고, 상업 승인 절차를 확인하는 게 순서야.

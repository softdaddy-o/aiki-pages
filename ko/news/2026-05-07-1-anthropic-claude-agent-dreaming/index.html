Anthropic, Claude 에이전트 dreaming 공개

Anthropic이 2026년 5월 6일 Claude Managed Agents의 'dreaming' 연구 프리뷰를 공개했어. 과거 세션과 메모리 저장소를 읽어 중복·충돌·낡은 정보를 새 메모리로 정리하는 비동기 작업이고, 별도 beta header와 입력 제한이 붙어 있어.

무슨 일이 일어났나

Anthropic이 2026년 5월 6일 공식 문서로 Claude Managed Agents의 dreaming 연구 프리뷰를 공개했어. dream은 과거 세션과 메모리 저장소를 읽어 중복, 충돌, 낡은 정보를 새 메모리로 정리하는 비동기 작업이야.

공식 조건

  • beta header 2개: managed-agents-2026-04-01, dreaming-2026-04-21
  • 지원 모델 2개: Claude Opus 4.7, Claude Sonnet 4.6
  • 입력 제한: dream당 최대 100개 sessions
  • 지시문 제한: instructions 4,096자

의미와 운영 확인

장기 에이전트 작업에서는 컨텍스트 윈도우보다 정리되는 기억이 중요해져. 운영 전 확인할 것은 나눠 봐야 해.

  • 요금: 선택한 모델의 표준 API 토큰 단가로 청구
  • 사용량: usage 필드에서 확인
  • 적용 범위: 일반 Claude API나 Claude Code 전체 기능이 아님
  • 위험: 권한, 비용, 잘못된 기억 강화는 자체 평가 필요

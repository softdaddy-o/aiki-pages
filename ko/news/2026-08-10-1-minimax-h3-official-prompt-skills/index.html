MiniMax, H3 영상 모델용 공식 프롬프트 스킬 9종을 저장소에 공개했어

설치는 npx skills add 한 줄이고, 프롬프트 작성 스킬 1개와 스타일별 영상 생성 스킬 8개가 들어 있어. 8월 5일 첫 커밋 뒤 8월 9일에는 허깅페이스 모델 카드에서 이 폴더로 가는 링크가 들어갔고, 한국 시각 8월 10일 새벽 문서 수정으로 특정 회사 도구 전용이 아니라는 문장이 추가됐어.

프롬프트 작성법을 문서 대신 설치되는 스킬로 냈어

MiniMax가 H3 영상 모델용 공식 프롬프트 스킬 9종을 GitHub 저장소에 공개했어.

8월 5일에 첫 스킬이 올라왔고, 8월 9일에는 허깅페이스 모델 카드에서 이 폴더로 가는 링크가 들어갔어. 문서 링크가 아니라 npx skills add 한 줄로 받아 쓰는 형식이야.

구성은 프롬프트 작성 스킬 1개와 스타일별 영상 생성 스킬 8개야. 전부 받을 수도 있고 하나만 골라 받을 수도 있어.

스킬 9종이 나눠 맡는 일

  • h3-prompt-writing: 입력 방식 5개(T2VA, I2VA, FL2VA, L2VA, Ref2VA)에 맞춰 프롬프트 필드 이름과 섹션 순서를 그대로 유지하도록 안내해
  • 스타일 스킬 8종: 제품 광고, 3D 애니메이션, 종이공예 스톱모션, 브랜드 홍보, 뮤직비디오 자막, 협동 게임 인트로, 종이 콜라주 해설, 손그림 합성 영상
  • 문서 언어: 스타일 스킬 8종은 영어판과 중국어판 SKILL.md를 같이 담았고, 프롬프트 작성 스킬은 아직 영어판만 있어

특정 도구 전용이 아니라고 문서에 명시했어

한국 시각 8월 10일 새벽에 들어간 문서 수정이 이 부분이야. h3-prompt-writing이 특정 회사 도구 전용이 아니라, 로컬 파일을 읽을 수 있는 에이전트면 어디서든 쓸 수 있다고 적었어.

원문 문장은 “Portable to any agent that can read local files”야. 외부 API 호출이나 MiniMax 전용 실행 환경이 필요 없다는 뜻이고, 이 수정은 MiniMax 직원이 아니라 외부 기여자가 올렸어.

저장소는 7월 30일에 생겼고 별은 2,964개야. 스킬을 기여하거나 개선하면 API 크레딧을 준다고 README에 적어놨어.

영상 생성을 자동화에 넣을 때 확인할 것

  • 어떤 입력 방식으로 부를지: 텍스트만 넣을지, 첫 프레임을 줄지, 참조 영상을 줄지에 따라 프롬프트 구조가 달라져. 스킬이 갈라주는 지점이 여기야.
  • 한국에서 직접 돌릴 계획인지: 오픈웨이트 라이선스는 한국을 제외 지역으로 뒀어. 스킬은 프롬프트 문서라 이 제한과 별개지만, 가중치를 내려받아 직접 운영할 거면 라이선스부터 확인해야 해.
  • 아직 바뀌는 중이라는 점: README가 스킬을 계속 고치는 중이라고 적었어. 사내 워크플로우에 그대로 고정하기보다 복사본을 두고 쓰는 게 안전해.

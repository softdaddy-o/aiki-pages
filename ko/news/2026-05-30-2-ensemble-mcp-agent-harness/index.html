ensemble-mcp — Claude Code에 벡터 메모리와 드리프트 감지를 추가하는 MCP 서버

ensemble-mcp는 Claude Code 같은 에이전트 하네스에 벡터 메모리, 드리프트 감지, 모델 라우팅 등 8가지 기능을 추가하는 Python MCP 서버야. LLM API 호출 없이 ONNX Runtime 임베딩(~5ms)과 SQLite로만 로컬에서 돌아가.

ensemble-mcp는 Python MCP 서버야. Claude Code나 Codex처럼 실행 환경을 담당하는 하네스에 붙어서 벡터 메모리, 드리프트 감지, 모델 라우팅, 컨텍스트 압축, 세션 지속성, 코드베이스 인덱싱 8가지 기능을 추가해줘.

설계 원칙이 독특해. LLM API를 완전히 빼놨거든. ONNX Runtime 임베딩(응답 속도 5ms 이하), numpy 코사인 유사도, SQLite 저장소로만 돌아가. 메모리와 검색에 따로 API 비용이 발생하지 않아.

이 서버가 정의하는 공식은 명확해: Agent = Model + Harness. 하네스는 모델을 에이전트로 만드는 모든 코드와 설정이고 — Claude Code와 Codex는 파일시스템, 배시, 샌드박스 같은 실행 레이어를 맡아. ensemble-mcp는 그 위에 메모리와 상태 레이어를 얹는 거야. 세션 간 기억, 코드베이스 인덱스, 드리프트 감지, 컨텍스트 압축이 다 여기 들어가.

pip 설치 후 Claude Code MCP 서버 설정에 추가하면 돼. 로컬 실행이라 추가 API 비용 0원으로 세션 사이에도 컨텍스트를 이어가고 싶은 사람한테 맞는 도구야.

Simon Willison이 Claude Fable 5에 프롬프트 하나만 주고 3D 게임을 받았어

설계 결정을 더 묻지 말라고 못 박은 지시 한 줄로 시작해서, 저장소에 커밋 17개가 쌓이고 브라우저에서 도는 게임이 나왔어. 3D 라이브러리 선택, 텍스처 생성, 경비원 추적 로직까지 사람이 개입하지 않았어. 다만 본인 평가는 '완성된 게임으로는 평범하다'야.

돌아가는 데까지는 갔는데, 재미까지는 못 갔어

“구현은 프롬프트 한 번으로 됐는데, 재미는 안 됐어.”

Simon Willison이 8월 5일 Claude Fable 5에 브라우저용 3D 게임을 시켰어. 프롬프트에 “추가 설계 결정을 나한테 묻지 마”라는 조건을 넣고 그대로 뒀고, 저장소에는 커밋 17개가 쌓였어.

너구리가 경비원을 피해 물건을 훔치는 게임이야. 브라우저에서 바로 돌아가고, 코드와 작업 기록도 저장소에 그대로 있어.

사람이 안 정한 것들이 꽤 많아

  • 라이브러리: 3D 렌더링에 Three.js를 골랐어. 프롬프트에는 어떤 라이브러리를 쓰라는 말이 없었어.
  • 텍스처: gpt-image-2로 이미지를 미리 만들어 저장소에 넣는 방식으로 처리했어. 생성 스크립트도 파일로 남아 있어.
  • 게임 로직: 손전등으로 주변을 비추는 경비원, 뒤 단계에 나오는 냄새 추적 개, 밤이 갈수록 어려워지는 난이도까지 알아서 넣었어.
  • 소리: 음원 파일 없이 브라우저에서 소리를 만들어 내는 방식으로 배경음을 붙였어.

2022년에 같은 걸 해봤을 때랑 비교돼

저자는 2022년에 같은 아이디어를 GPT-3와 DALL-E로 한 번 시도했어. 그때 남긴 이미지 2장을 이번 프롬프트에 참고 자료로 같이 넣었어.

그때는 콘셉트 그림까지였고, 이번엔 실행되는 결과물이 나왔어. 같은 사람이 같은 아이디어로 4년 간격을 두고 찍은 비교라 조건이 꽤 깔끔해.

그래서 어디까지 맡길지 볼 때

  • 평가: 저자 본인은 “완성된 게임으로는 평범하고, 프롬프트 하나에서 나온 출발점으로는 인상적”이라고 적었어. 재미있는 게임을 설계하는 건 아직 사람 몫이라는 게 결론이야.
  • 조건: 정적 파일로 배포되는 브라우저 게임이라 실행 환경이 단순해. 로그인, 데이터베이스, 결제가 붙는 업무 시스템에 같은 기대를 걸긴 일러.
  • 표본: 실행 한 번, 프로젝트 하나야. 바이브 코딩 도구를 고르는 벤치마크로 쓸 수치는 아니야.
  • 써볼 만한 자리: 판단 기준이 이미 사람 머릿속에 있고 구현만 남은 탐색용 시제품이라면, 한 번에 던져 보고 결과를 보고 판단해도 늦지 않아.

yfinance (와이파이낸스)

Yahoo Finance 공개 데이터를 Python에서 빠르게 훑고 묶어보는 데 강한 리서치용 라이브러리

원본

yfinance (와이파이낸스)은(는) 로컬, 코딩 도구에서 자동화 흐름을 설계하고 운영하는 데 도움이 되는 자동화 프레임워크입니다. 문서가 어느 정도 갖춰져 있고 유지 신호도 보여서 스타 23333개와 외부 언급 7개를 함께 보면 먼저 살펴볼 만합니다.

설치

`pip install yfinance`로 설치합니다. Python 환경만 있으면 별도 API 키 없이 바로 쓸 수 있어요.

사용 예시

`yf.Ticker("AAPL").history(period="1mo")`로 개별 종목의 가격·재무·배당·옵션 데이터를 탐색하고, `yf.download(["AAPL", "MSFT"], start="2026-01-01")`로 여러 종목의 과거 데이터를 한 번에 받아 CSV나 차트로 씁니다.

연동 방식

pandas·matplotlib와 묶어 notebook에서 리서치 파이프라인을 만들거나, 받은 데이터를 CSV로 떨궈 작은 대시보드의 입력으로 연결합니다. 다만 결과가 돈이나 고객에게 영향을 주는 자리라면 정식 [API](/ko/wiki/api/) 벤더 계약으로 넘겨야 해요.

리뷰

yfinance는 Yahoo Finance의 공개 데이터를 Python에서 가져오기 쉽게 만든 라이브러리예요. Ticker 함수로 종목의 가격·재무·배당·옵션을 탐색하고, download로 여러 종목의 historical data를 한 번에 받아 리서치 초안이나 작은 대시보드의 입력으로 씁니다.

핵심 판단 기준은 “리서치 초안용으로 쓸지, 정식 데이터 계약으로 갈지”예요. 시장 데이터는 가져오는 것보다 쓸 권리와 품질 책임이 더 중요한데, yfinance는 빠른 실험에는 편하지만 공식 데이터 공급까지 대신해 주지는 않아요.

README도 Yahoo와 제휴·승인·검증된 도구가 아니며 데이터 사용 권리는 Yahoo 약관을 보라고 경고합니다. 그래서 개인 리서치·교육·prototype에는 충분히 유용하지만, 고객-facing 제품이나 투자 자동화에는 위험 신호가 빨리 켜지는 도구예요.

사용 예시

Ticker 함수로 개별 종목 또는 여러 종목의 가격, 재무 정보, 배당과 액면분할 같은 이벤트, 옵션 데이터를 탐색합니다. download로는 여러 ticker의 과거 데이터를 한 번에 받아 notebook, 리서치 CSV, 작은 dashboard의 입력으로 써요.

API 벤더 계약을 맺기 전, 아이디어 검증이나 교육용 분석을 빠르게 해 보는 용도에 특히 잘 맞아요. Yahoo Finance 화면에서 손으로 확인하던 데이터를 Python으로 반복 수집하면 시간을 크게 줄일 수 있습니다.

확인할 점

README의 important notice가 가장 중요해요. yfinance는 Yahoo의 공식 제품이 아니고, Yahoo Finance API는 personal use를 전제로 한다고 적혀 있습니다.

비공식 데이터 접근은 schema 변경, rate limit, 누락, 수정 데이터 지연에 취약해요. 결과가 돈이나 고객에게 영향을 주면 vendor 계약, 데이터 출처 추적, 오류 보정 절차가 별도로 필요합니다. 데이터 품질과 모델 결과는 benchmark로 분리해서 검증하는 게 좋아요.
